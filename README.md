# Tekken-Character-Select-Webpage
This is a simple project which aims to recreate the character selection menu of from tekken 6 as closely as possible using PHP, HTML, CSS and JavaScript.
It is important to note that the character renders, names and icons, as well as the logo are not owned by me. All copyright belongs to the respective owners.
Tekken Warehouse: https://tekkenwarehouse.com
